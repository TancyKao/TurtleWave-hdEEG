# Dataset API Reference

The Dataset module wraps `wonambi.Dataset`, adding optional memory-mapped
backing for large EEGLAB `.set`/`.fdt` files and reading EEGLAB metadata
(start time, events) out of the underlying `.mat` structure.

::: turtlewave_hdEEG.dataset
    options:
      show_root_heading: true
      show_source: true
      heading_level: 2
