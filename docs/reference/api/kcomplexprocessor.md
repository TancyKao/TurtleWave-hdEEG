# K-Complex Processor API Reference

The K-Complex Processor module provides functionality for detecting
K-complexes in sleep EEG data. It reuses `ParalSWA`'s CSV/SQLite export
helpers internally, since K-complex parameters are structurally identical to
slow-wave parameters.

::: turtlewave_hdEEG.kcomplexprocessor
    options:
      show_root_heading: true
      show_source: true
      heading_level: 2
