# Sleep Cycle Processor API Reference

The Sleep Cycle Processor module detects NREM-REM sleep cycles from a scored
hypnogram and persists them (plus per-stage sleep durations) to
`neural_events.db` and the annotation XML.

::: turtlewave_hdEEG.cycleprocessor
    options:
      show_root_heading: true
      show_source: true
      heading_level: 2
