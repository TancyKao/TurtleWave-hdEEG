# Detector Extensions API Reference

The Extensions module subclasses Wonambi's `DetectSpindle` and `DetectSlowWave`
to re-apply custom thresholds, RMS windows, smoothing, and polarity that
Wonambi's own constructors would otherwise overwrite.

::: turtlewave_hdEEG.extensions.ImprovedDetectSpindle
    options:
      show_root_heading: true
      show_source: true
      heading_level: 2

::: turtlewave_hdEEG.extensions.ImprovedDetectSlowWave
    options:
      show_root_heading: true
      show_source: true
      heading_level: 2
